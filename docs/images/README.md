# Visual Reference Assets

These are **repository-owned SVG reference diagrams recreated from the themes and concepts illustrated in the conversation**. They are not exact copies of the web image previews displayed in chat; those transient preview images were not available as original downloadable files.

## Assets

- [Product modules overview](product-overview.svg) — campaign, automation, chatbot/AI, help desk, contacts and analytics.
- [System architecture](system-architecture.svg) — web/app layer, event/queue processing, data and external integrations.
- [Messaging flow](messaging-flow.svg) — outbound campaign delivery and inbound webhook routing.

SVGs are editable vector assets and can be embedded in Markdown or opened in a browser/design application.
